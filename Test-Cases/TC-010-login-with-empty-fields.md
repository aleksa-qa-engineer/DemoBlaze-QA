# TC-010 — Login with empty fields
**ID:** TC-010  
**Название:** Login with empty fields  
**Предусловие:** Открыта форма авторизации.
## Тестовые данные

- **Username:** пусто
- **Password:** пусто
- ## Шаги

1. Открыть сайт DemoBlaze.
2. Нажать **Log in**.
3. Оставить поля Username и Password пустыми.
4. Нажать **Log in**.
## Ожидаемый результат

- Авторизация не выполняется.
- Отображается сообщение о необходимости заполнить обязательные поля.
- Форма авторизации остаётся открытой.
- ## Фактический результат

- Отображается сообщение **"Please fill out Username and Password."**
- Авторизация не выполняется.
- Форма авторизации остаётся открытой.
- ## Статус

**Passed**
