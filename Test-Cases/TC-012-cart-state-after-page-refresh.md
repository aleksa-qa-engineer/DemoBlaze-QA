# TC-012 — Cart state after page refresh
## Основная информация

- **ID:** TC-012
- **Название:** Сохранение корзины после обновления страницы
- **Модуль:** Cart
- **Тип тестирования:** Functional
- **Приоритет:** Medium
- **Предусловие:** В корзину добавлен товар.
- ## Тестовые данные

- **Товар:** Samsung Galaxy S6
- ## Шаги

1. Открыть сайт DemoBlaze.
2. Добавить товар в корзину.
3. Перейти в корзину (Cart).
4. Обновить страницу браузера (F5).
5. Проверить содержимое корзины.
## Ожидаемый результат

1. После обновления страницы товар остаётся в корзине.
2. Информация о товаре отображается корректно.
## Фактический результат

После обновления страницы состояние корзины сохранилось корректно.
## Статус

**Passed**
