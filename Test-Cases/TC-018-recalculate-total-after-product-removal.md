# TC-018 — Recalculate total after product removal
## Основная информация

- **ID:** TC-018
- **Название:** Пересчёт общей суммы после удаления товара
- **Модуль:** Cart
- **Тип тестирования:** Functional
- **Приоритет:** High
- **Предусловие:** В корзине находятся как минимум два товара.
- ## Тестовые данные

- **Действие:** Удаление одного товара из корзины.
- ## Шаги

1. Открыть корзину (Cart).
2. Проверить текущую общую сумму Total.
3. Нажать Delete рядом с одним из товаров.
4. Проверить содержимое корзины.
5. Проверить пересчитанную общую сумму Total.
## Ожидаемый результат

1. Выбранный товар удаляется из корзины.
2. Общая сумма Total автоматически пересчитывается.
3. Итоговая стоимость соответствует сумме оставшихся товаров.
4. Ошибок не возникает.
## Фактический результат

1. Выбранный товар успешно удалён.
2. Общая сумма автоматически пересчиталась.
3. Итоговая стоимость соответствует сумме оставшихся товаров.
4. Ошибок не обнаружено.
## Статус

**Passed**
