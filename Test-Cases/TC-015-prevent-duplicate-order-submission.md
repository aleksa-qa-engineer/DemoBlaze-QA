# TC-015 — Prevent duplicate order submission
## Основная информация

- **ID:** TC-015
- **Название:** Защита от повторной отправки заказа
- **Модуль:** Order Checkout
- **Тип тестирования:** Functional
- **Приоритет:** High
- **Предусловие:** Пользователь авторизован, в корзине есть товар, форма оформления заказа заполнена.
- ## Тестовые данные

- **Действие:** Повторное нажатие на кнопку Purchase.
- ## Шаги

1. Открыть корзину и нажать Place Order.
2. Заполнить обязательные поля формы.
3. Несколько раз нажать Purchase.
4. Проверить результат оформления заказа.
## Ожидаемый результат

1. Заказ оформляется только один раз.
2. Отображается одно окно подтверждения заказа.
3. Дублирование заказа не происходит.
4. Интерфейс работает корректно.
## Фактический результат

1. Отобразилось одно окно подтверждения заказа.
2. Создан один заказ.
3. Дублирования заказа не произошло.
4. Ошибок в работе интерфейса не обнаружено.
## Статус

**Passed**
