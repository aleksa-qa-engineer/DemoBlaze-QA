# TC-003 — Registration with empty fields
**ID:** TC-003  
**Название:** Registration with empty fields  
**Предусловие:** Открыта форма регистрации.
## Шаги
1. Нажать **Sign up**.
2. Не заполнять поля Username и Password.
3. Нажать **Sign up**.
## Ожидаемый результат

Система не выполняет регистрацию и предлагает заполнить обязательные поля.
## Фактический результат

Отображается сообщение **"Please fill out Username and Password."**  
Регистрация не выполняется.
## Статус

**Passed**
