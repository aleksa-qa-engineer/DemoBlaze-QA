# TC-016 — Add multiple different products
## Основная информация

- **ID:** TC-016
- **Название:** Добавление нескольких разных товаров
- **Модуль:** Cart
- **Тип тестирования:** Functional
- **Приоритет:** High
- **Предусловие:** Пользователь находится в каталоге товаров DemoBlaze.
- ## Тестовые данные

- **Товар 1:** Samsung Galaxy S6
- **Товар 2:** Sony vaio i5
- ## Шаги

1. Открыть каталог товаров.
2. Открыть карточку первого товара и добавить его в корзину.
3. Вернуться в каталог.
4. Открыть карточку второго товара и добавить его в корзину.
5. Перейти в корзину.
6. Проверить названия товаров, цены и общую сумму Total.
## Ожидаемый результат

1. Оба товара добавлены в корзину.
2. Названия товаров отображаются корректно.
3. Цена отображается для каждого товара.
4. Общая сумма Total рассчитана правильно.
## Фактический результат

1. Добавлены два разных товара.
2. Оба товара отображаются в корзине.
3. Названия корректные.
4. Цена отображается у каждого товара.
5. Общая сумма Total рассчитана правильно.
## Статус

**Passed**
