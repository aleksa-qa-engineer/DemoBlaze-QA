# TC-013 — Remove product from cart
## Основная информация

- **ID:** TC-013
- **Название:** Удаление товара из корзины
- **Модуль:** Cart
- **Тип тестирования:** Functional
- **Приоритет:** Medium
- **Предусловие:** В корзине находится хотя бы один товар.
- ## Тестовые данные

- **Товар:** Samsung Galaxy S6
- ## Шаги

1. Открыть сайт DemoBlaze.
2. Перейти в корзину (Cart).
3. Найти добавленный товар.
4. Нажать Delete рядом с товаром.
## Ожидаемый результат

1. Товар удаляется из корзины.
2. Удаление выполняется корректно.
3. Удалённый товар отсутствует в списке товаров корзины.
## Фактический результат

1. Товар удалился из корзины.
2. Удаление произошло корректно.
## Статус

**Passed**
